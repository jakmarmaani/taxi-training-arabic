# Taxi and Private Hire Training Practice

A free English–Arabic study website for the supplied Edinburgh taxi and private hire training materials. The homepage links to four separate module pages. Each page contains bilingual course notes, the module questions and answer reveals.

## Pages and files

- `index.html` — home page with section links and question counts
- `module-1.html` to `module-4.html` — one page for each training section
- `course-guide.js` — bilingual topic summaries covering the supplied manuals
- `questions.js` and `extra-questions.js` — bilingual questions and multiple-choice answer checks
- `answers.js` — bilingual answer key and suggested answers for written activities
- `app.js` and `style.css` — page rendering and responsive layout

Written notes are saved only in the learner’s browser on that device. They are not sent to anyone.

The manuals and answer guide are marked as City of Edinburgh Council training material from 2020. The website provides bilingual study summaries and practice answers; it is not an official Council publication. Check current licensing conditions and legal requirements before relying on it for formal training. Obtain permission before republishing the original documents or a full verbatim translation publicly.
