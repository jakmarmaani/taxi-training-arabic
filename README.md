# Taxi and Private Hire Training Practice

A free, bilingual English–Arabic practice website for taxi and private hire training. Each training section has its own page. It uses plain HTML, CSS and JavaScript, so it needs no paid service or server.

## Pages and files

- `index.html` — home page and links to all four sections
- `module-1.html` to `module-4.html` — one page per section
- `questions.js` — bilingual questions, multiple-choice options and objective answer notes
- `answers.js` — bilingual suggested answers for written activities
- `app.js` — page rendering, answer reveal, checks and local written notes
- `style.css` — responsive styling and Arabic right-to-left text

## Use locally

Download or unzip the project, then open `index.html` in a web browser. Written notes are saved in that browser on that device and are not sent to anyone.

## Publish with GitHub Pages

1. Open the repository `jakmarmaani/taxi-training-arabic` on GitHub.
2. Select **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then select **Save**.
5. Wait for GitHub Pages to publish, then open the website link shown in the Pages settings.

## Questions and answers

The objective answers and written model answers are shown in both English and Arabic. Some written prompts are reflective, so the displayed response is a suggested example. The question bank covers the identifiable activities and questions in the supplied training PDFs. Compare the pages with the PDFs before treating this as a verbatim, exhaustive transcription.

The source materials are marked City of Edinburgh Council 2020. Check permission before republishing source text or a full translation publicly, and confirm current licensing conditions before using the material for formal training.
